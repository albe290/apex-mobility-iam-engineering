# Security / Publishing Guidance

This repository is intended for public portfolio use.

Before committing evidence or automation:

- Remove secrets, tokens, certificates, private keys, and client secrets.
- Review tenant IDs, object IDs, usernames, email addresses, IP addresses, and URLs before publication.
- Do not upload production customer data.
- Use fictional APEX identities and sanitized evidence where possible.
- Keep destructive or privileged automation behind explicit approval gates.
